# OkakOS 67 🚀

Самый окакный дистрибутив Linux на базе Arch! 

## Фичи:
* **Hyprland** из коробки (потому что тайлы — это круто).
* Инновационная файловая система **Fat67** (эксклюзивно в нашем установщике).
* Загрузочный ASCII-арт "67", который пугает всех, кто смотрит в монитор при включении ПК.
* Сикс Севен одобряет: миллион пасхалок "67" во время установки системы.

## Как собрать ISO-образ:
Чтобы магия случилась и ISO образ собрался автоматически (потому что мы ленивые и собираем через GitHub Actions), вам нужно:

1. Зайти в свой репозиторий на GitHub.
2. Нажать **Add file** -> **Create new file**.
3. В названии файла написать: `.github/workflows/build.yml`
4. Вставить код, который дал вам помощник, и нажать **Commit changes**.
5. Перейти во вкладку **Actions**, налить чай и подождать 10-15 минут, пока собирается ваш `OkakOS-ISO`.
