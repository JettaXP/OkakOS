# OkakOS 67 🚀

Самый окакный дистрибутив Linux на базе Arch! 

## Фичи:
* **Hyprland** из коробки (потому что тайлы — это круто).
* Инновационная файловая система **Fat67** (эксклюзивно в нашем установщике).
* Загрузочный ASCII-арт "67", который пугает всех, кто смотрит в монитор при включении ПК.
* Сикс Севен одобряет: миллион пасхалок "67" во время установки системы.
